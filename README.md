# CBSE School – Premium Indian Educational Website Demo

A complete, modern, visually impressive, and fully responsive demonstration website for an Indian CBSE Educational Institution. Designed and developed from scratch strictly using native **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)**.

---

## 🌟 Project Overview

This is a demonstration website intended for:
- **Portfolio presentations**
- **Client showcases & educational agency pitches**
- **Educational website design showcases**
- **Future turnkey customization for real educational institutions**

It portrays a premium, disciplined, and technologically modern CBSE school with authentic Indian academic aesthetics, balanced whitespace, editorial typography, and polished interactive micro-features.

---

## 🛠️ Strict Technology Stack

In strict compliance with the project specifications, **no frameworks, libraries, build tools, or npm packages are used**:

- **HTML5**: Clean, semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) with ARIA roles and accessibility tags.
- **CSS3**: Custom design system using CSS Variables, Flexbox, CSS Grid, clamp(), min(), max(), media queries, and smooth cubic-bezier transitions.
- **Vanilla JavaScript (ES6+)**: Custom component logic for mobile drawers, sticky navigation, active section tracking, modals, accordions, carousel slider, gallery filter, fullscreen lightbox, counters, and form validation.
- **Zero Dependencies**: Directly executable by double-clicking `index.html` in any modern web browser.

## 🎨 Design System & Color Palette

The visual direction follows an authentic Indian premium institutional aesthetic:

| Role | Color Name | Hex Code | Purpose |
| :--- | :--- | :--- | :--- |
| **Primary** | Primary Navy | `#142B49` | Core identity, primary text, dark backgrounds |
| **Secondary** | Royal Blue | `#2457A6` | Accents, links, secondary buttons, highlights |
| **Accent** | Warm Gold | `#D8A84E` | Badges, CTAs, borders, achievement counters |
| **Surface** | Soft Cream | `#FAF8F3` | Alternating section backgrounds, cards |
| **Neutral** | White | `#FFFFFF` | Core card surfaces, clean spacing |
| **Accent Light** | Light Blue | `#EDF3FA` | Subtle tags, icons containers, input focus |
| **Body** | Body Text | `#465467` | High-contrast readable paragraph typography |
| **Muted** | Muted Text | `#7B8794` | Captions, secondary timestamps, disclaimers |

### Typography
- **Headings**: `Playfair Display` (Serif) – Imparts editorial dignity, academic prestige, and elegance.
- **Body & Navigation**: `Inter` (Sans-Serif) – Maximum legibility across all viewport resolutions.

## 📑 Detailed Website Sections (All 14 Included)

1. **Section 01 – Top Information Bar**: Live notification bar displaying session dates, office hours, and phone contact with SVG icons.
2. **Section 02 – Navigation Bar**: Sticky header, logo typography with shield crest, primary navigation links, "Admission Enquiry" CTA, and accessible animated mobile hamburger drawer.
3. **Section 03 – Hero Section**: Full-width architectural campus visual, headline, welcome badge, dual CTAs, and three compact highlight pills.
4. **Section 04 – Welcome / About the School**: Two-column layout with institutional overview, Vision, Mission, three core pillars, and high-resolution classroom composition.
5. **Section 05 – Academic Programmes**: Five developmental cards (Foundational, Primary, Middle, Secondary, Senior Secondary) with interactive curriculum modals.
6. **Section 06 – Facilities and Infrastructure**: Eight campus infrastructure cards (Smart Classrooms, Science Labs, Computer & Robotics Suite, Central Library, Sports Turf, Art Studio, GPS Transport, and 24/7 Security).
7. **Section 07 – Achievements and School Highlights**: Rich navy & gold backdrop, four scroll-triggered animated statistic counters (1000+, 50+, 20+, 100%), and three development pillars.
8. **Section 08 – Events and Announcements**: Four interactive sample school events with date badges, "Read More" schedule modals, and a dynamic "View All Events" expander.
9. **Section 09 – Campus Moments Gallery**: Responsive CSS grid with six real-time filter categories (All, Campus Life, Classrooms, Sports, Cultural, Learning) and a full-featured keyboard- and touch-accessible lightbox.
10. **Section 10 – Parent Testimonials**: Authentic fictional parent reviews in a responsive auto-sliding carousel with manual arrow controls and dot pagination indicators.
11. **Section 11 – Admission Enquiry CTA**: High-contrast full-width gradient banner driving parent enquiry conversions.
12. **Section 12 – FAQ Section**: Smooth single-expanded accordion addressing curriculum, facilities, admissions, and fictional website disclosure.
13. **Section 13 – Contact and Enquiry Form**: Campus address, phone, email, and hours on the left; robust interactive admission form on the right with Indian phone number regex validation, email format checking, and simulated submission confirmation banner.
14. **Section 14 – Footer**: Four-column layout, social media icons, copyright, floating back-to-top button, and institutional disclaimer.
